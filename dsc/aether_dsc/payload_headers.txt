# NVRTC-clean payload manifest — committed, sorted, one path per line, same
# discipline as tests/expected_tests_*.txt: a manifest, not a count, so a
# same-commit swap cannot pass silently.
#
# Every aether header listed here is claimed NVRTC-clean (the seven rtc/
# shims, AETHER_BITCOPY, no offsetof-in-constant-expression) and
# `tools/rtc_seal_check.py` gates that claim on every run. This is the
# ground-truth closure measured for `benchmarks._hawk_arm.grav_body` (hawk
# repo) via a real `nvcc -MD` build — not a directory walk: measured,
# ~28 other aether headers (aether/accum/, aether/banded/,
# aether/chunk/, aether/interop/, aether/residency/, aether/backend/,
# aether/err/, aether/dtype/Format.h, some aether/view/Make*.h) reach std
# headers the rtc/ shim set does not cover (<algorithm>, <cstring>,
# <stdexcept>, DLPack's own includes) — profiling them is deliberately out
# of scope here; the manifest grows deliberately, one committed line at a
# time, exactly like the test-count manifests: add a path, run this
# script, commit the diff.
#
# `aether/aether.h` (the umbrella) is deliberately not listed: it
# transitively includes every one of the ~28 excluded headers, so it is
# not yet part of the payload either.
